# Ôn tập Triết học Mác – Lênin

Web ôn tập và kiểm tra trắc nghiệm gồm 463 câu, chia theo 3 chương.

- **Ôn tập:** làm từng câu và xem giải thích lý thuyết, xem nhanh đáp án, ôn lại câu sai, tìm kiếm theo từ khóa.
- **Kiểm tra:** đề ngẫu nhiên có tính giờ, bắt buộc làm ở chế độ toàn màn hình (thoát sẽ khóa bài và ghi nhận số lần thoát). Chấm điểm thang 10 và xem lại bài kèm giải thích.

Đây là web tĩnh (`index.html` + `data.js`), chạy trực tiếp trên GitHub Pages.
